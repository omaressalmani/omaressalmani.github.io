### Billiard Ball Trajectory Test Bench

This project focuses on **measuring billiard ball trajectories** using a specially designed test bench.  
The principle is simple yet precise: a ball is launched in a straight line using a ramp, then strikes a **rotating disk** driven by a stepper motor, inducing rotation after the bounce.  

The test bench consists of a **motor, power supply, microcontroller, control electronics**, and a fully integrated **mechanical structure**.  
A camera is mounted above the bench to capture the ball's movement, and an **image processing algorithm** measures trajectories and rotations.  

The main objectives were:  
- Design a **new disk rotation system** using bearings and belts to improve performance and correct observed issues.  
- Optimize the **mechanical structure of the test bench** using **CAD in Catia** and fabricate prototypes in the **FabLab** via rapid prototyping and stratoconception.
